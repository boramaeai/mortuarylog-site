# MortuaryLog — public pages

The public pages for **MortuaryLog**, a case log for funeral service and embalmer
apprentices in the United States.

- [Privacy policy](https://boramaeai.github.io/mortuarylog-site/privacy/)

## This directory is generated

Do not edit the HTML here. It is built from the app repository by
`tools/build_site.mjs`, from a single source document, and a test there fails if the
two drift. A privacy policy that disagrees with the app is a false statement, so there
is only ever one copy of the words.
